# Popover

A styled wrapper over the `@base-ui` Popover for the new system, built with Tailwind CSS v4 and shadcn.

## Imports

```js
import { Popover, PopoverTrigger, PopoverContent, PopoverClose } from '@strapi/design-system/next';
```

## Usage

```jsx
<Popover>
  <PopoverTrigger render={<Button variant="outline">Open</Button>} />
  <PopoverContent align="start">…</PopoverContent>
</Popover>
```

`PopoverContent` forwards the positioning props (`side`, `align`, `sideOffset`, `alignOffset`,
`collisionAvoidance`, `collisionBoundary`, `collisionPadding`, `sticky`) to the underlying positioner.
