# Tag

A label with a button, usually to remove a filter or a selected value.

## Imports

```js
import { Tag } from '@strapi/design-system/next';
```

## Usage

```jsx
<Tag label="Remove filter" onClick={removeFilter}>
  date is null
</Tag>
```

## Accessibility

- The button is named by `label`, so `getByRole('button', { name: 'Remove filter' })` finds it. Always pass a `label`.
- A disabled Tag sets `disabled` and `aria-disabled="true"` on its button, and never calls `onClick`.

## Migrating from the legacy Tag

```diff
- import { Tag } from '@strapi/design-system';
+ import { Tag } from '@strapi/design-system/next';
```

| Legacy prop          | Next API                                                   |
| -------------------- | ---------------------------------------------------------- |
| `icon` (required)    | `icon`, optional, `<Cross />` by default                   |
| `label`              | `label`                                                    |
| `disabled`           | `disabled`                                                 |
| `onClick`            | `onClick`                                                  |
| `children`           | `children`                                                 |
| Flex props           | `className` with Tailwind classes, on the root `<div>`     |
