# Drawer

A panel that slides in from an edge of the screen, built on the Base UI `Drawer`.

Note: this Drawer does not work like the Radix one. With Radix, the side panel is a `Sheet`, and the `Drawer` is a
bottom panel. With Base UI, the Drawer opens from any side, so it is also the side panel.

## Imports

```js
import { Drawer, DrawerContent, DrawerTitle } from '@strapi/design-system/next';
```

## Usage

`swipeDirection` sets the edge that closes the Drawer: `right` gives a panel on the right side. There is no close (X)
button: use `DrawerClose`.

## With components of the old system

Known limits, because the old system and Base UI do not know each other's layers:

- The calendar of a DatePicker is hidden from screen readers while the Drawer is open.
- When Escape closes the Drawer, `onOpenChange` gets the reason `imperative-action`, not `escape-key`.
